# PsiUI

A modern Python DaisyUI component library for FastHTML, with full component coverage, theming, interactivity, 
and extensibility.

---

`psi-daisy` is a modern, DaisyUI component framework for FastHTML. It provides:

- A real Python component API
- Full DaisyUI component coverage
- Tailwind class support
- A complete theming engine
- Interactive components powered by HTMX
- A plugin architecture
- A FastHTML-powered documentation site
- FastHTML DaisyUI demos

This project is currently under active development.
